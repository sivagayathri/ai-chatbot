AI Chatbot Backend (Node.js + Ollama)

This is a simple AI-powered chatbot backend built with Node.js, Express, and Ollama.
It exposes a /webhook endpoint that accepts user messages and responds with an AI-generated reply using an Ollama model (e.g., mistral, llama2).
🚀 Features
Webhook endpoint (/webhook) for chatbot integration
Parses both JSON and URL-encoded requests
Uses Ollama as the AI engine (local LLMs)
Clean and minimal structure – easy to extend for real-world use cases
